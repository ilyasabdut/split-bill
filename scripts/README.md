# Scripts

This folder contains utility scripts organized by functionality and purpose.

## 📁 Folder Structure

### `demos/`
Demonstration and visualization scripts for project features and architecture.

- **`phase1_demo.py`** - Interactive demonstration of Phase 1 modular architecture

## 🚀 Usage

### Running Demos
```bash
# Run Phase 1 architecture demonstration
python scripts/demos/phase1_demo.py

# Or via Makefile
make demo-phase1
```

### Purpose of Demos
- **Architecture Visualization**: Show modular structure and component relationships
- **Feature Demonstrations**: Illustrate key functionalities
- **Educational Tool**: Help understand project organization and improvements

## 📊 Demo Output

The Phase 1 demo shows:
- Project structure overview
- Modular architecture components
- Code quality tools status
- Configuration management
- Development workflow

## 🔧 Adding New Scripts

When adding new scripts:
1. Categorize by purpose (demos, utilities, etc.)
2. Add appropriate README documentation
3. Update this main scripts README
4. Consider adding Makefile commands for easy access
